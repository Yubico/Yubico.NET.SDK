# Pass 2 review packet

Use the [final ledger](pass-2-review-ledger.md) for card decisions and future PR attribution. The [master](pass-2-applet-master.md), its review and correction records, and the [decision log](pass-2-review-decisions.md) retain their original code pins and conclusions. They do not describe the current upstream tree.

For delivery, `yubikit-pass2-base` succeeds `yubikit-docs-audit` as the base for future Pass 2 PRs. References to the old PR base in the packet are historical. This baseline does not close any cards.

The [frozen audit archive](https://github.com/Yubico/Yubico.NET.SDK/tree/db72706b9ebda1f9ff95fede125e270c755966d0/docs/research/documentation-audit) contains the supporting evidence and the [approved writing style](https://github.com/Yubico/Yubico.NET.SDK/blob/db72706b9ebda1f9ff95fede125e270c755966d0/docs/research/documentation-audit/records/style.md).
