The new bounded implementation imports none of those historical modules, copies no old SDK path,

toolchain. It supplies command-line reporting and generator-output emission only: no warning,
analyzer, restore, compiler-skip or resource-lifetime policy override. It excludes the toolchain file-app

1. Requires the exact successful/quiescent v2 build receipt, one selected fresh build step, zero warnings,

   it requires that exact empty set rather than inventing build test counts.

   sources separately. All real sample source files and mapped formatted files must participate.
3. Retains actual imports, generated NuGet props/targets/dgspec, assets, root policy, source/config text,
   actual SDK/compiler identities, output assembly attributes, emitted Core XML and original Csc outputs.
4. Proves both package-supplied NetAnalyzers 9.0.0 DLLs and their NuGet/import-order identity. Effective
   `EnableNETAnalyzers=false` is expected for the explicit package, not interpreted as analyzer absence.
   Effective policies remain per-project: Tests.Shared initially receives Recommended from root props
   despite later setting IsTestProject=false. The annotations context also receives Recommended.
5. Reconciles complete declared/restored direct and transitive project graphs, unique paths/IDs, full
   node data, edges, late ProjectReference closure and actual per-owner obj reference/bin output DLLs.
   Only unordered node/edge collections are canonicalized; nested target data is preserved, not flattened.
   Actual package compile references and resolved runtime/native output copies bind restored assets and
   native package identities. No library/host Version is assumed equal to SDK Version.
6. Keeps compiler/reference/analyzer/output/native binaries externally under the unique home attempt;
   versioned evidence contains text snapshots and binary identities only. Current-source/live checks
   require those exact preserved binary bytes, not regenerated substitutes or a skipped missing-file check.
