Treat the fixture as wrapper/phase regression evidence, not a final-spec oracle. `TestStateExtensions.WithSecurityDomainSessionAsync` borrows one SmartCard connection from shared `WithConnectionAsync`, awaits callback, and uses distinct lexical using scopes for unauthenticated reset and actual test session. Both fresh factories receive supplied configuration and state version. The helper borrows parameters, does not dispose them, and does not pass its token into callback calls automatically. Its source ownership pattern supports sequential sessions, while the actual shared connection helper owns connection disposal (B1/A/shared owner, not a fresh whole-helper acceptance).

`SecurityDomainStateRestoringTests.Track` retains one state. xUnit instance teardown requests reset with an independent 60-second CTS only when Track was called. This is stronger than same-token local finally but still an attempted reset with uncancellable admitted exchanges; no verified factory contents or elapsed-time guarantee. Static 100-second CTS fields in test classes start at class initialization, persist across test instances and are not disposed. Later tests can inherit expiration; source presence of a token is not responsive-cancellation coverage.

`ScpCertificates` arranges exact certificate object identities by issuer/subject name equality and key usage. Its `IsSelfSigned` helper name does not verify signature. It has no disposal owner and failure leaves caller-loaded certs uncollected. a/c helpers load PKCS12 collections, export private D, clone into ECPrivateKey and return a selected certificate list; exported D and omitted CA/root objects need separate cleanup. PEM loader partial failure leaves prior certificates, and GetSki creates an undisposed TLV view; blindly disposing it before returning Value would invalidate that value (C's TLV owner). These paths preserve SD-IMP-008, with public PEM/PKCS12 fixture bytes left unchanged.

Fixture certificate byte data is public test material, not newly acquired trust. B6 independently observed a root serial mismatch with the allowlist literal: the root is `49FE7DC08A4228EACD18D73914C3D30FDCC31950`, while the two literals are the intermediate `7F4971B0AD51F84C9DA9928B2D5FEF5E16B2920A` and `6B90028800909F9FFCD641346933242748FBE9AD`. This packet leaves the encrypted PKCS12 opaque: no decryption/import or trust-store change. No extra claim about its private content, exact selected chain or final device rejection follows.
