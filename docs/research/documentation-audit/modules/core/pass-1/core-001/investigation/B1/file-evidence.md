## Shared units and narrow dependencies

All 126 assigned shared units were read at exact inventory ranges. The ownership guide was read completely for neighboring conditions; Core README/CLAUDE, nested test instructions, workflow/style/house style and Tests.Shared instructions/README supplied caller context. PublicApi HID compatibility tests and their exercise helper were read completely: production internal adapters are constructed reflectively, then copy/zero caller reports, preserve caller source and return fake input; disposal count is one. That is a consumer-compatibility shape, not hardware acceptance.

CLI shared getters specify concrete transport arrays. The common CLI base and `src/Cli.Shared/src/Device/DeviceSelector.cs` establish device filtering/preference and explicit request propagation; individual applet command bodies are outside these getter units' disposition. Tests.Shared bound-transport getters keep requested transport distinct from available flags; lazy binding helpers and real recorder transmit/dispose paths were read. Recorder transactions are no-op and response queues are supplied byte arrays, so they prove no PC/SC isolation.

The L4 SVG's full text labels and PNG render were inspected. Both show applet preference, one typed connect, known-member claim and explicit borrowed/hidden-connection ownership. They omit error/quarantine/wait states as a high-level happy-path diagram; C007 preserves them as associated unchanged dependencies. Historical async plan sections retain their original proposal-era authority and exclusions.

Narrow implementation dependencies include `YubiKeyDevice`, `SharedDeviceInfoRead`, `IYubiKey`, `ApplicationSession`, `ConnectionSessionGuard`, `ExchangeGuard`, `PcscProtocol`, FIDO disposal wake, compatibility adapters, reader-state/context and PC/SC interop calls. Reading these dependencies grants no whole-unit disposition outside the packet. B2/B3/B4/B5/B6 and nine applet boundaries retain their original owners. Firmware gates, response-owner/TLV details and complete Windows/native implementation are explicitly excluded here.
