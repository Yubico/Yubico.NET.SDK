## Analyzer capture correction

The consumer build succeeded, but its first capture guard equated EnableNETAnalyzers=false with
skipped analysis. In this repository, the explicit pinned **NetAnalyzers9.0.0** package disables duplicate
SDK-bundled selection while supplying both canonical analyzer assemblies to Csc. The original policy,
arguments, failed capture and v1 tools/manifest are retained unchanged.

The versioned `analyzer-package-1` correction pins imported-package/property provenance and requires
both exact canonical DLLs in actual Csc arguments. It preserves warning levels/warnings-as-errors,
RunAnalyzersDuringBuild/no-skip policy, all source/reference/analyzer/config membership checks and SDK
default-hook checks. It changes evidence interpretation rather than compiler or SDK settings. Static
and prepared checks passed before reuse. The accepted consumer **second capture reused the intact
successful compilation**, requiring no rebuild. Shipping first capture used the same corrected checks.
