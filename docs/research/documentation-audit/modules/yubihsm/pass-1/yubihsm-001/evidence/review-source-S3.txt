<h1 id="interacting-with-a-yubihsm-2">Interacting with a YubiHSM 2</h1>

<p><code>Yubico.YubiKey.YubiHsmAuth</code> provides an easy way to programmatically manage the YubiHSM Auth application on the
YubiKey. While this SDK also supports the calculation of session keys, it is instead recommended for developers to rely
on the <a href="https://docs.yubico.com/hardware/yubihsm-2/hsm-2-user-guide/">YubiHSM SDK</a> for interactions with the YubiHSM 2.</p>
<h2 id="yubihsm-sdk">YubiHSM SDK</h2>
<p>Once credentials are added to the YubiHSM Auth application, use
the <a href="https://docs.yubico.com/hardware/yubihsm-2/hsm-2-user-guide/">YubiHSM SDK</a> (and bundled tools) to establish a
secure session with a YubiHSM 2 device and perform operations on it.</p>
<p>The <a href="https://docs.yubico.com/hardware/yubihsm-2/hsm-2-user-guide/hsm2-sdk-tools-libraries.html#yubihsm-shell">YubiHSM Shell</a>
tool supports authentication with YubiHSM Auth credentials in both interactive mode and command-line mode. Once the user
is authenticated, all YubiHSM Shell commands can be used. Refer
to <a href="https://docs.yubico.com/hardware/yubikey/yk-5/tech-manual/yubihsm-auth.html#using-yubihsm-auth-with-yubihsm-shell">this guide</a>
for more information.</p>
<p>It is also possible to use low-level commands to communicate natively with a YubiHSM 2. The individual commands (
documented <a href="https://docs.yubico.com/hardware/yubihsm-2/hsm-2-user-guide/hsm2-cmd-reference.html">here</a>) are implemented
by
the <a href="https://docs.yubico.com/hardware/yubihsm-2/hsm-2-user-guide/hsm2-sdk-tools-libraries.html#libyubihsm">libyubihsm</a> C
library.</p>
<h2 id="yubihsm-2-secure-channel">YubiHSM 2 secure channel</h2>
<p>In order to establish an encrypted and authenticated session with a YubiHSM 2, the YubiHSM Auth application must follow
the YubiHSM 2 secure channel protocol. This protocol is based on the Global Platform Secure Channel Protocol 03 (SCP03),
but there are two important differences:</p>
<ul>
<li>The YubiHSM 2 secure channel protocol does not use APDUs, so the commands and possible options do not match the
complete SCP03 specification.</li>
<li>SCP03 uses a set of three long-lived AES keys, while the YubiHSM 2 secure channel uses a set of two long-lived AES
keys.</li>
</ul>
<p>The two long-lived keys used in the YubiHSM 2 authentication protocol include an ENC key and a MAC key. In order to
successfully create a secure channel, the long-lived keys in the YubiHSM Auth credential and YubiHSM 2 device must be
identical.</p>
<p>Those long-lived key sets are used by the YubiHSM Auth application to derive a set of three session-specific AES-128
keys using the challenge-response protocol as defined in SCP03:</p>
<ul>
<li>Session Secure Channel Encryption Key (S-ENC): used for data confidentiality.</li>
<li>Secure Channel Message Authentication Code Key for Command (S-MAC): used for data and protocol integrity.</li>
<li>Secure Channel Message Authentication Code Key for Response (S-RMAC): used for data and protocol integrity.</li>
</ul>
<p>Session-specific keys can be requested from the YubiHSM Auth application and are returned to the caller. These
session-specific keys are used to encrypt and authenticate commands and responses with a YubiHSM 2 device during a
single session. The session keys are discarded afterwards.</p>
