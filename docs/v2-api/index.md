# YubiKit V2 API reference

API reference for the next generation of the YubiKey .NET SDK.

> [!IMPORTANT]
> **Alpha documentation**
>
> APIs may change. This reference follows the `yubikit` branch.
> V2 is intended for evaluation and is not yet recommended for production use.

## SDK modules

V2 targets .NET 10. Select a namespace to browse its public types and members.

| Namespace | Purpose |
| --- | --- |
| [Yubico.YubiKit.Core](xref:Yubico.YubiKit.Core) | Device discovery and connections |
| [Yubico.YubiKit.Ctap2](xref:Yubico.YubiKit.Ctap2) | CTAP2 authenticator operations |
| [Yubico.YubiKit.Management](xref:Yubico.YubiKit.Management) | Device configuration |
| [Yubico.YubiKit.Oath](xref:Yubico.YubiKit.Oath) | OATH credentials |
| [Yubico.YubiKit.OpenPgp](xref:Yubico.YubiKit.OpenPgp) | OpenPGP operations |
| [Yubico.YubiKit.Piv](xref:Yubico.YubiKit.Piv) | PIV operations |
| [Yubico.YubiKit.SecurityDomain](xref:Yubico.YubiKit.SecurityDomain) | Secure channels |
| [Yubico.YubiKit.WebAuthn](xref:Yubico.YubiKit.WebAuthn) | WebAuthn client APIs |
